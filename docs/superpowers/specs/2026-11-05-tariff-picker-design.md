# Витрина тарифов: аккордеон с преимуществами (A+B)

Дата: 2026-11-05. Макет, одобренный владельцем: холст «Тарифы кабинета: варианты»,
артборды «A+B · Стандарт раскрыт» / «A+B · Роскошный раскрыт»
(https://claude.ai/artifact/Pt19tCUz3QWRKhC5dR8uG9, файл `project/Hybrid.dc.html`).

## Зачем

На витрине (`TariffPickerGrid`, `/subscription/purchase`) у всех тарифов одно и то же
описание: 4 из 5–7 строк совпадают (локации, YouTube, безлимит, скорость). Разница
(устройства, скорость, премиум) теряется, страница с четырьмя карточками ~2500 px.
Чип «↓ 70 ГБ» рядом со словом «безлимит» читается как противоречие — это трафик
белых списков (у нас считается только он).

## Что строим

1. **Блок «Во всех тарифах»** над списком: до 8 пунктов плиткой 2×2, у каждого значок.
   Текст и значки — настройка бота `TARIFF_COMMON_FEATURES`, строки вида
   `globe: Все локации`. Пусто → блока нет.
2. **Тарифы — аккордеон.** Свёрнутый: (плашка) + название + строка «для кого» слева,
   цена и подпись «в месяц» справа, шеврон. Раскрыт ровно один; нажатие на раскрытый
   сворачивает его. По умолчанию раскрыт текущий тариф пользователя, иначе
   выделенный (`is_highlighted`), иначе первый.
3. **Раскрытый тариф** — преимущества строками «плитка-значок + текст»:
   - `**3 устройства** · можно до 10` (вторая часть — только если можно докупить);
   - `**Выделенная скорость** до 500 Мбит/с` (если задана скорость; «до 500 Мбит/с» не рвётся);
   - `**70 ГБ** в месяц на белые списки` (если лимит > 0; «в месяц/в неделю/в день» по режиму сброса);
   - `Премиум-серверы` — золотом, плитка с золотым контуром (если флаг);
   - `**100 ₽ за устройство** · выгоднее всех` — зелёным, только у одного тарифа с
     наименьшей ценой за устройство среди показанных;
   - затем цена крупно `300 ₽ в месяц`, под ней зелёным `283 ₽/мес при оплате за 3 месяца`,
     затем кнопка действия (та же логика `tariffAction`, что сейчас).
4. **Плашки:** выделенный тариф — «★ Чаще всего выбирают» (золотом, без золотой рамки);
   текущий — «Текущий тариф» (вместо плашки выделения).
5. Заголовок обычной покупки в тарифном режиме: «Выберите тариф».

Подзаголовка под заголовком нет (владелец убрал).

## Новые данные

Бот (форк `SayonaraQ/remnawave-bedolaga-telegram-bot`), миграция **0142**, таблица `tariffs`:

| Поле | Тип | Смысл |
|---|---|---|
| `tagline` | `VARCHAR(160) NULL` | строка «для кого» под названием |
| `speed_limit_mbps` | `INTEGER NULL` | выделенная скорость, Мбит/с |
| `has_premium_servers` | `BOOLEAN NOT NULL DEFAULT false` | строка «Премиум-серверы» |

Редактируются в админке кабинета (форма тарифа). Явный `null` в PUT очищает
`tagline`/`speed_limit_mbps`; отсутствие поля — не трогает.

`GET /cabinet/subscription/purchase-options` (тарифный режим):
- у каждого тарифа `tagline`, `speed_limit_mbps`, `has_premium_servers`, `max_device_limit`
  (эффективный потолок для покупки: `tariff.max_device_limit or MAX_DEVICES_LIMIT`, не выше
  общего `MAX_DEVICE_LIMIT`; `null`, если докупить нельзя — цена устройства ≤ 0,
  `device_limit == 0` или потолок ≤ базового лимита);
- на верхнем уровне `common_features: [{icon, text}]` из `TARIFF_COMMON_FEATURES`.

Формат `TARIFF_COMMON_FEATURES`: пункты через перевод строки или `;`; пункт `значок: текст`,
значки `globe | youtube | infinity | plus | check`; без известного значка — весь пункт
текстом со значком `check`; пустые пропускаются; максимум 8 пунктов, текст ≤ 80 символов.

Описание (`description`) остаётся для бота (Telegram) и как запасной вариант: если у тарифа
нет `tagline`, раскрытая карточка показывает `description` как раньше (`pre-line`).

## Цены

- Цена «в месяц» — период 30 дней, если он есть, иначе первый период с подписью «за N дн.».
  Посуточный — «в день» (`dailyPriceQuote`). Без периодов — «Гибкая оплата».
- Все цены — после промо-скидки (`applyPromoDiscount`), как сейчас. При скидке в раскрытой
  карточке рядом с ценой зачёркнутая старая и «−N%» (как сейчас).
- Строка «N ₽/мес при оплате за K месяцев»: самый длинный период с `months ≥ 2`,
  цена/месяцы, округление до рубля; показывается, только если дешевле цены «в месяц».
- Целые рубли в ₽ — без копеек («300 ₽»), иначе как сейчас.
- «За устройство» = цена «в месяц» / базовый лимит устройств; кандидаты — не посуточные,
  с ценой > 0 и лимитом > 0; плашка только при ≥ 2 кандидатах и единственном минимуме.

## Не делаем

Простой вид (`TariffPickerLite`), лендинг, подарки, Telegram-меню бота, тексты описаний
тарифов. Мультитарифа у нас нет — его ветку не ломать, но и не дорабатывать.
